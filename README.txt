# MENTOR — first version

A free, local-first habit and gym tracker designed for iPhone.

## Included
- Manual START MY DAY button that records the exact wake-up/start time.
- Daily habit checklist and independent habit streaks.
- Saved past day sessions; a new day starts only when you press START MY DAY.
- Workout logging (exercise, weight, reps) and workout history.
- Progress overview, dark appearance, and offline app shell.

## Important
Your records are stored locally in the browser on this device. There is no account, subscription, analytics, or server sync. Clearing Safari website data can erase records. This first version does not automatically detect when you wake up; it records the time when you tap START MY DAY.

## Put it on your iPhone for free
1. On a computer, create a free GitHub account if you don't already have one.
2. Create a new public repository named `mentor-app`.
3. Upload all files in this folder to the repository root (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Open the Pages URL on your iPhone in Safari.
7. Tap **Share → Add to Home Screen → Add**.

You can also open `index.html` on a computer to preview the app, but installing it on iPhone as a home-screen app requires a secure HTTPS host such as GitHub Pages.
